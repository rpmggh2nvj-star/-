## Turf Logic（競馬予想アプリ）

`keiba-yosou.html` をブラウザで開くだけで使えます。インストール・通信・アカウント登録は不要で、
入力したデータは端末の外に出ません（保存もブラウザの localStorage のみ）。

### 使い方

1. **レース設定** … コース（芝／ダート）、距離、馬場状態、想定ペース、予算を入力します。
   「ペース自動判定」で、登録した逃げ馬・先行馬の数からペースを推定できます。
2. **出走馬** … 1頭ずつ、馬番・単勝オッズ・近3走の着順・騎手・調教・距離適性・馬場適性・
   斤量・馬体重増減・脚質を入力します（最大18頭）。
3. **「この条件で予想する」** を押すと、指数・推定勝率・推奨買い目が表示されます。

まずは「サンプル読込」で8頭立てのデモデータを入れて動作を確認するのがおすすめです。
「保存」「呼出」で入力内容を端末に残せます。

### 予想ロジック

指数は、オッズを**除いた**以下の要素を加点・減点して算出します。

| 要素 | 内容 |
| --- | --- |
| 近走フォーム | 前走・2走前・3走前の着順を 5:3:2 で加重 |
| 騎手／調教 | S〜Dの5段階評価 |
| 距離適性／馬場適性 | ◎○△×の4段階。馬場適性は道悪ほど比重が上がる |
| 展開 | 想定ペース × 脚質（ハイなら差し・追込、スローなら逃げ・先行が有利） |
| 斤量 | 出走馬平均との差 |
| 馬体重増減 | −4〜+8kg を適正圏とし、外れるほど減点 |
| 枠順 | 芝1600m以下は内枠、ダートはやや外枠が有利 |

この指数を softmax で勝率に変換し、さらにオッズから求めた市場推定勝率と
**幾何ブレンド**（市場側の重み 0.55）して最終的な推定勝率としています。
オッズは単独では極めて強い予測子なので、モデルを市場で補正して過信を防ぐ狙いです。

結果表示の各値の意味は次のとおりです。

- **指数** … オッズを除いた能力評価
- **推定勝率** … 指数にオッズを加味した最終予想
- **期待値** … 推定勝率 × 単勝オッズ（単勝の期待回収率）
- **市場比** … 推定勝率 ÷ 市場推定勝率。1.00 超で「人気以上に評価できる馬」＝妙味

上位5頭に ◎○▲△△ の印を付け、市場比1.20以上の馬に「妙味」、0.80以下の馬に
「過剰人気」のタグを表示します。

### 買い目

◎を軸に、単勝・複勝・馬連流し・ワイド・三連複（軸1頭流し）を提案し、
入力した予算を券種ごとに配分して1点あたりの金額まで表示します。
市場比の高い妙味馬が見つかった場合は、その馬の単勝とワイドも追加されます。

### 注意

指数・推定勝率はあくまで入力値をもとにした簡易モデルによる計算結果であり、
的中を保証するものではありません。馬券の購入は自己責任・余裕資金の範囲で行ってください
（20歳未満は購入できません）。
