# 転記スペック（製剤学 過去問 画像→テキスト）

対象画像（1問につき2枚）:
- 問題:  /tmp/claude-0/-home-user--/ae2f27f6-7584-5838-943f-1523bc550e20/scratchpad/qcrop2/Q0NN.jpg
- 解答解説: /tmp/claude-0/-home-user--/ae2f27f6-7584-5838-943f-1523bc550e20/scratchpad/acrop2/A0NN.jpg
（NN は3桁ゼロ埋め。例: 問16 → Q016.jpg / A016.jpg）

画像の性質:
- 印刷された問題集のスマホ撮影。裏写り/ゴーストが薄く重なることがある → 濃くシャープな前景文字だけ読む。
- Q画像 上部に「必須」or「理論」バナーと「問NN」。続いて問題文と選択肢1〜5。
- A画像 各選択肢の正誤（正/誤）＋解説、末尾付近に「解答 N」ボックス。
  A画像は上下に隣接問題が写り込むことがある → 左上「解説 NN」と当該「解答」ボックスで対象問だけを拾う。

出力（JSONオブジェクト、キーは問番号の文字列）:
{
  "16": {
    "n": 16,
    "q": "【理論】問題文<br>1 選択肢1<br>2 選択肢2<br>3 …<br>4 …<br>5 …",
    "a": "2",
    "e": "1誤 …<br>2正 …<br>3誤 …<br>4誤 …<br>5誤 …"
  }
}

ルール:
- q 冒頭に必ずバナー種別を付す: 【必須】 または 【理論】。
- 選択肢・解説内の改行は <br>。「1つ選べ」「2つ選べ」の別も q に残す。
- a は解答ボックスの数字。複数解答は全角読点で "2、4" のように。
- 図・表・工程図など文章化できない要素は該当箇所に「（図は画像参照）」と明記（創作しない）。
- 数値・記号・化合物名・単位・濃度・温度・pH など、読み取りに少しでも自信がない箇所は
  その直後に ⚠要確認 を付ける（例: "pH 6.8⚠要確認"）。判読不能な字は □ とし ⚠要確認。
- 絶対に内容を推測で創作しない。見えない部分は「（判読不可）⚠要確認」。
