# 青問 → Anki 一括変換パイプライン

## 使い方
1. このフォルダに元PDF(青問の写真60ページ)を `source.pdf` として置く
2. `claude` を起動して以下を指示:
   「README.mdの手順に従い、source.pdfの全問題をAnki化して。
    進捗ファイル(all_texts.json)にある問1〜15はスキップし、
    問16以降を読み取ってテキスト化を完了させて」

## パイプライン手順(Claude Code向け)
1. `pdftoppm -jpeg -r 250 source.pdf hr` で全ページ画像化
2. 各ページを左右分割(左=問題、右=解答解説)。コントラスト1.15倍補正
3. 問題バナー検出で1問ずつ切り抜き:
   - 必須=赤バナー (r>140, r-g>60, r-b>60)
   - 理論=青バナー (b>120, b-r>40, b-g>25) ← 赤だけだと18問漏れるので注意
   - 行ごとの該当ピクセル数 > 幅×0.06 の連続帯をバナーとみなす
   - bands2.json に検出済み座標あり(再利用可)
4. 解答側は左端14%幅の赤タグ(問N)で分割。数が合わないページは
   問題側の位置から比例計算+上下4%パディングでフォールバック
5. 各問題crop画像をClaude自身が読み取り、問題文・選択肢・解答・解説を
   テキスト化。読み取りに自信がない数値・記号には「⚠要確認」を付ける
6. all_texts.json に {"問番号": {"q":..., "a":..., "e":...}} 形式で追記
7. genanki でデッキ生成(build_deck.py 参照)。カード構成:
   - 表: 問番号 + 問題テキスト + 切り抜き画像
   - 裏: 解答 + 解説テキスト + 解答切り抜き画像
8. 完成した .apkg を出力
